# Lok Sabha Election Analysis

## Overview
This project analyzes Lok Sabha election data to identify voting trends, party performance, and regional insights.

## Tools Used
- SQL
- Tableau
- Google sheet

## Features
- Data Cleaning
- Party-wise Analysis
- State-wise Insights
- Dashboard Visualizations
- Trend Analysis
